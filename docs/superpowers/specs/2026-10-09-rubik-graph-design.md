# Кубик Рубика + граф наклеек — дизайн

## Цель
Минималистичный сайт из двух панелей. Слева 3D-кубик Рубика, справа граф из 54 вершин (по одной на наклейку). Панели связаны в обе стороны: действие в одной сразу отражается в другой, с анимацией.

## Стек
Vite + TypeScript, three.js (кубик), SVG (граф), Vitest (тесты модели). Раскладка графа фиксированная, физика не нужна.

## Модель (единый источник правды)
- Состояние: массив из 54 цветов, индексы наклеек 0..53 (6 граней по 9).
- 18 ходов (U, U', U2, D, D', D2, L, L', L2, R, R', R2, F, F', F2, B, B', B2), каждый задан перестановкой индексов.
- Кубик и граф только читают состояние и отправляют в модель ходы. Модель не знает про UI.
- Ход выдаёт список циклов перестановки, чтобы UI мог анимировать движение наклеек по дуге.

## Граф
- 54 вершины, цвет вершины = цвет наклейки.
- Рёбра: соседние наклейки внутри грани (сетка 3×3) и через рёбра кубика между гранями.
- Позиции вершин фиксированы (развёртка-крест из 6 граней).
- Поворот слоя перемещает цвета между позициями вершин по циклам перестановки. Вершины едут по дуге, анимация синхронна с анимацией слоя на кубике.

## Управление
Слева:
- мышь по пустому месту вращает кубик целиком;
- перетаскивание по грани поворачивает слой с анимацией;
- клавиши U, R, F и т. д. делают ходы (Shift для обратного хода).

Справа:
- вершину можно тянуть вдоль соседнего ребра; если дотянуть до соседней позиции, поворачивается слой, в котором лежит вершина; иначе вершина возвращается на место;
- клик по вершине тоже делает ход.

Внизу одна тонкая строка: «скрамбл · сброс · отмена».

## Оформление
Минимализм: две равные панели, без шапки и меню, один фон, цвета кубика. Адаптивность до ширины планшета достаточна.

## Тесты
Vitest на модель:
- четыре одинаковых хода дают исходное состояние;
- ход и обратный ход компенсируются;
- сохраняется ровно 9 наклеек каждого цвета;
- последовательность из известного алгоритма (например, (R U R' U')×6) возвращает собранное состояние.

Интерфейс проверяется вручную в браузере.

## Вне объёма (YAGNI)
